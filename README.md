# Career Networking Platform

## Project Description
This project is a database system for a Career Networking Platform. It allows users to create professional profiles, connect with other users, view companies, and apply for jobs.

## Main Entities
- Users
- Companies
- Jobs
- Applications
- Connections

## Database Features
The database uses primary keys and foreign keys to create relationships between the tables. Companies can post multiple jobs, users can apply for jobs, and users can connect with other users.
